# task-management

Responsive Bootstrap task management dashboard with dummy-data authentication and browser-based CRUD operations.

## Run locally

Open `index.html` in a browser, or serve the folder with any static web server. The app uses Bootstrap 5 from CDN and stores demo data in `localStorage`.

### Demo accounts

- `alex@taskflow.app` / `password` - Admin
- `mia@taskflow.app` / `password` - Member
- `jordan@taskflow.app` / `password` - Manager

Registering a new account is also supported. Data is local to the current browser and is intended for demonstration only.
